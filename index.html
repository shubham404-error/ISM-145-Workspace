    Collection shortcuts

    Tab / Shift+Tab: next / previous field.
    Enter / Shift+Enter: same column in the next / previous visible row, from plain text fields.
    Escape: cancel a shortcut, close the datapoint book or FTR review.

    Dropdowns, autocomplete fields and date pickers keep their native keys. Outside the table, browser shortcuts are unchanged.

    Shortcuts are enabled by default. Alt actions work across collection fields, including dropdowns and dates. Alt+N and Alt+R also work from the collection toolbar. The enable/disable preference is saved in this browser.

    Move row and its children

    Children move with their parent. A move that changes an existing parent relationship is not applied, including where repeated segment names would select a different parent.
